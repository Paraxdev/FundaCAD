# Project the model

Project (P) copies existing geometry into the sketch so you can draw against it.

<!-- shot: sketch-project | purple projected edges from a block -->

Click an edge of a body, a face to take its outline, or a curve from an earlier sketch. Projected curves are purple and follow the model when it changes, so they cannot be dragged. Select one and choose Break Link to turn it into an ordinary curve.

Project only sees what was made before the sketch in the History.
