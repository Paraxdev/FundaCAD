# Repeat shapes

Linear Pattern lays copies out in a row along any direction, and Circular Pat. spaces them around a centre. Rect Pattern is the third choice, for a grid with rows and columns. The copies stay tied to the original.

<!-- shot: sketch-pattern-rect | rectangle pattern with Nx and Ny boxes -->

Choose the tool and click the curves to repeat, then click where the pattern starts and move the mouse to set the spacing. A linear pattern follows the direction of the mouse, and hold Alt to turn it freely instead of in steps. Type the counts into the boxes next to the cursor. The original counts as one copy, so a count of 3 makes two more.

A circular pattern starts at six copies over 360 degrees. Drag the centre dot to where you want it.

You cannot select or dimension a single copy. Draw it by hand if one needs to differ.
