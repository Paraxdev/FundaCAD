# Linear, circular and rect pattern

Linear Pattern repeats a body along a line, Circular Pattern repeats it around an axis, and Rect Pattern repeats it in a grid of rows and columns.

![A plate with a row of five holes](../img/pattern-holes.png)

Select the body first. If you select a face that a cut made, such as the wall of a hole, the pattern repeats that cut, which gives a row of holes from one.

Drag the arrow to set the spacing, and press [ or ] to change the count. For a circular pattern, click an edge to turn about, or press C to switch between the origin and the middle of the part.

A rect pattern has an X arrow and a Y arrow, one for the gap between columns and one for the gap between rows. Type the copies in each direction into the boxes, and press [ or ] to change the X count.
