# Draft and thread

Draft tilts a face so a wall leans back a little, and Thread adds a real helical thread to a round face.

<!-- shot: draft-thread | drafted wall beside a threaded shank -->

For Draft, click the face and set an angle up to 60 degrees. The pull direction is Z, and X cycles through X, Y and Z.

For Thread, click the round face, then set the pitch in the P box and the length in the L box. A thread needs at least one full turn.
