# The node editor

When the surface patterns are not enough, Edit graph opens a node editor along the bottom of the screen, with your part above it as a live preview.

<!-- shot: render-node-editor | node editor with Noise wired to Output -->

Press Shift+A to add a node, such as Noise, Scratches, Ramp, Math or Mix. Drag from one dot to another to connect them, and end everything in the Output node, which takes roughness, bump and colour. Done closes the editor.
