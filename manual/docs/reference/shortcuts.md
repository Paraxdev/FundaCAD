# Keyboard and mouse shortcuts

Press ? at any time to see the same list inside the app. It is built from the same table that handles the keys, so what it shows is what works. On a Mac, use Cmd wherever this page says Ctrl.

Single letters are ignored while you are typing in a box, so typing a name or a number never starts a tool by accident. A few letters mean different things in a sketch than in the model, and the two tables below show both.

## In the model

| Key | What it does |
| --- | --- |
| S | Sketch |
| E | Extrude |
| Q | Press/Pull |
| F | Fillet |
| B | Chamfer |
| M | Move |
| I | Measure |
| K | Split Body |
| U | Clean Up |
| O | Offset Plane |
| Ctrl+U | Union |
| Ctrl+B | Subtract |
| Ctrl+I | Intersect |
| H | Hide the selected bodies |
| Shift+H | Show all bodies |
| 1 | Select faces |
| 2 | Select whole bodies |
| 3 | Select a body first, then its faces |
| X | See through the model to select what is behind |
| Shift+X | Show edges only (wireframe) |
| L, C, R, A, P | Start a sketch with Line, Circle, Rectangle, Arc or Project |

## In a sketch

| Key | What it does |
| --- | --- |
| L | Line |
| R | Rectangle |
| C | Circle |
| A | Arc |
| D | Dimension |
| T | Trim |
| O | Offset |
| F | Sketch Fillet |
| P | Project |
| M | Move/Rotate |
| E | Finish the sketch and start Extrude |
| Q | Finish the sketch and start Press/Pull |
| Esc | Back out one step, and leave the sketch when nothing is left to cancel |
| Ctrl+Z | Undo the last sketch action |

## Anywhere

| Key | What it does |
| --- | --- |
| Ctrl+K or Ctrl+F | Command palette, to search for and run any command |
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+N | New document |
| Ctrl+O | Open |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save As |
| Ctrl+E | Export |
| Ctrl+, | Preferences |
| Ctrl+Alt+S | Show or hide the Items card |
| Ctrl+Alt+H | Show or hide the History card |
| Ctrl+` | Show or hide the console |
| Home or F6 | Fit the view to the model |
| Shift+Home | Reset the camera |
| ? | Show the shortcut list |
| Delete or Backspace | Delete the selected face, or the selected History step |
| Esc | Cancel the running tool, or clear the selection |
| F2 | Rename the selected History step |

## Mouse

| Action | What it does |
| --- | --- |
| Right-drag | Orbit |
| Shift + right-drag | Pan |
| Middle-drag | Pan |
| Wheel | Zoom |
| Click | Select a body, then a face on it |
| Drag a box to the right | Select what lies fully inside the box |
| Drag a box to the left | Select anything the box touches |
| Shift + drag a box | Add to the selection |
| Tab while boxing | Cycle between everything, only faces and only edges |
| Ctrl+click | Add to the selection, in the viewport and in the lists |
| Shift+click | Select a run of rows in the Items card |

## While a tool is running

These only apply while the tool named in the first column is active.

| Tool | Key | What it does |
| --- | --- | --- |
| Any tool with a value box | Tab | Lock the field you are in and go to the next |
| Any tool with a value box | Enter | Finish |
| Any tool | Esc | Cancel |
| Extrude | Alt+S | Extrude both ways from the sketch |
| Extrude, Press/Pull, Draft, Offset Face | Ctrl+click | Add another area or face |
| Press/Pull | T | Click another face to stop at |
| Fillet and Chamfer | Tab | Switch between fillet and chamfer |
| Fillet and Chamfer | Shift+click | Take exactly the edge you clicked |
| Thicken | S | Grow the wall on both sides |
| Draft | X | Cycle the pull direction between X, Y and Z |
| Linear and Circular Pattern | [ and ] | Fewer or more copies |
| Circular Pattern | C | Switch between the origin and the middle of the part |
| Move | Shift + drag | Move in finer steps |
| Sketch patterns | Alt + move | Let the angle go free instead of snapping |
| Text | Ctrl+Enter | Place the text |
| Pick tools such as Union | Esc | Stop picking |
