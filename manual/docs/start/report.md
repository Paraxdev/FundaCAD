# Report a problem

When something goes wrong, or does not do what you expected, tell us. Help > Report a Problem… opens the report. The bug button at the bottom right of the view, the Home screen and the safe mode banner open the same one, and so does the Report action on the notice that says the geometry engine stopped.

**Describe it.** Write what happened and what you expected. This is the only box you have to fill in.

**Add a picture.** Save Picture… renders the 3D view and asks where to save `fundacad-report.png`. Drag that file into the issue on GitHub. A picture shows your design, so it is made only when you click.

**Open on GitHub.** This copies the whole report to the clipboard first, then opens a new Problem report on GitHub with the title, your description, the version and your system already filled in. Paste the report into the Report box and submit. Opening an issue needs a GitHub account.

**Copy report** only copies it, for when you would rather send it some other way.

## What a report holds

What will be sent shows the exact text before anything is copied. It holds:

- the version, the channel, your system and the web view the app runs in;
- whether safe mode is on and which plugins run;
- your description;
- the last steps you took and the last three errors, with their full details;
- the render pipeline's notes;
- the end of the app log, unless you untick it;
- the current document, only when you tick it.

User names in file paths are hidden in the log and in the errors. The document and the picture contain your design, so both are off until you choose them. A document too big for an issue is left out, and the report window says so: put the `.funda` file in a `.zip` and drag it into the issue yourself.

## What leaves your computer

Nothing, until you submit the issue on GitHub. FundaCAD only writes the clipboard, saves the picture where you choose, and opens the issue page in your browser.

## Copy it again

Signing in to GitHub, or a code it sends you, can replace what is on the clipboard. The app keeps your last report until it closes: Copy Again, on the message after the copy or in the report window, puts the same text back. It is never saved to disk.

## Ideas

Help > Suggest an Idea opens the Idea form on GitHub. Say what you are trying to make and what would help.
