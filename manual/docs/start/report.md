# Report a problem

When something goes wrong, or does not do what you expected, tell us. The report opens from any of these:

- Help > Report a Problem…
- the bug button at the foot of the view controls, on the right of the view;
- Report a problem, on the Home screen or on the safe mode banner;
- Report, on the notice that says the geometry engine stopped.

## Send a report

1. Write what happened and what you expected. This is the only box you have to fill in.
2. If a picture helps, click Save Picture…. It renders the 3D view and asks where to save `fundacad-report.png`.
3. Click Open on GitHub. The report is copied to the clipboard, and a new Problem report opens on GitHub with the title, your description, the version and your system filled in.
4. Paste the report into the Report box, drag in the picture if you saved one, and submit.

Opening an issue needs a GitHub account. Copy report only copies the text, for when you would rather send it some other way.

## What a report holds

What will be sent shows the exact text before anything is copied. It holds:

- the version, the channel, your system and the web view the app runs in;
- whether the geometry engine is connected, whether safe mode is on and which plugins run;
- your description;
- the last steps you took and the last three errors, with their full details;
- the render pipeline's notes;
- the end of the app log, unless you untick it;
- the current document, only when you tick it.

User names in file paths are hidden in the log and in the errors. The document and the picture show your design, so both are off until you choose them.

A document too big for an issue is left out, and the report window says so. Put the `.funda` file in a `.zip` and drag it into the issue yourself.

## What leaves your computer

Nothing, until you submit the issue on GitHub. FundaCAD only writes the clipboard, saves the picture where you choose and opens the issue page in your browser.

## Copy it again

Signing in to GitHub, or a code it sends you, can replace what is on the clipboard. Click Copy Again, on the message after the copy or in the report window, to put the same report back. The app keeps it in memory until it closes, never on disk.
