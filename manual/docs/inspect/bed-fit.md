# Bed fit check

Bed Fit Check tells you whether the whole model fits on your printer's bed. It is in the Print group on the rail.

![A bracket with a message that it fits the 220 by 220 by 250 mm bed](../img/bed-fit-result.png)

1. Pick Bed Fit Check under Print.
2. Choose a bed size from the list, or Custom to type the Width, Depth and Height.
3. A message says the model fits, or what percentage to scale it to so it does.

The check uses the overall size of the model as it sits, so it does not try turning it on the bed. The bed you choose is remembered for next time.
