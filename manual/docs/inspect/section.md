# Section

Section cuts the model open with a plane so you can see inside.

![A bracket cut along Z with the offset handle and value box](../img/section-handle.png)

Pick Section under Inspect, then a face, a plane, or the Z, X or Y axis. Z gives a horizontal slice. Drag the handle or type a distance, and press F to flip the kept half. The cut half stays as a faint ghost, and G changes how strong it is.

Section stays on while you work, so you can orbit and select. Press Esc to leave it.
