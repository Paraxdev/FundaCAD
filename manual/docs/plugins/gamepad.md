# Game controller

This plugin lets you move around the model with a game controller. It is on by default and does nothing until one is connected.

![The Game controller row in Preferences, Plugins, with its settings open](../img/prefs-gamepad.png)

Plug it in and press any button, FundaCAD only notices a controller after its first press. The left stick pans, the right stick rotates, the right trigger zooms in and the left trigger zooms out.

| Button | What it does |
| --- | --- |
| A | Enter, or a click while the cursor is on |
| B | Escape |
| X and RB | Undo and Redo |
| Y | Command palette |
| LB | Cursor on or off, then the left stick moves the cursor |
| View / Back | Reset Camera |
| Menu / Start | Save |
| Left stick click | Cycle Projection |
| Right stick click | Fit View |
| D-pad up, down, left, right | Top, Front, Isometric and Right views |

To change a button, open its Settings in Edit, Preferences, Plugins and pick a key or a command under Buttons. Pan speed, Rotate speed, Zoom speed, Cursor speed, Stick deadzone and the invert switches are there too.

On a Steam Deck, add FundaCAD to Steam as a non-Steam game and start it from there, so the app sees a controller. The trackpads keep working as a mouse.
