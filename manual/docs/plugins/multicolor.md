# Multi-material

This plugin says which body goes in which filament, with slots that line up with your printer's toolheads. It is off by default, so switch it on in Preferences, Plugins.

<!-- shot: multicolor-palette | Palette section with three filament slots -->

A Palette section appears in the Items card with a swatch and a name per slot. It needs the [Printer connection](printing.md) plugin on and the printer reachable. The dot is green when the slots match the printer, yellow when its filaments changed, and red when it did not answer. Sync filaments from printer copies its colours across.

Right-click a body and open Color to give it a slot. FundaCAD never invents slots, because a slot stands for a filament that is physically loaded.
