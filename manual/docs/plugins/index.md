# Plugins

A plugin adds something not everyone needs, such as screws, textures or a link to your printer. Most are on out of the box.

<!-- shot: prefs-plugins | Plugins page with a switch per plugin -->

| Plugin | What it is for |
| --- | --- |
| [Extra Parameters](extra-parameters.md) | Sliders, groups and saved sets of values |
| [Fasteners](screws.md) | Screws, nuts, washers and inserts |
| [Surface Texture](texture.md) | Knurling, ribs and other real textures |
| [Node Bodies](organic.md) | Smooth solids built from sized points |
| [3D Printing Toolbox](print-toolbox.md) | Holes and edges that print without supports |
| [Printer connection](printing.md) | Open a part in your slicer and send jobs |
| [Multi-material](multicolor.md) | Filament slots, off by default |
| [Game controller](gamepad.md) | Navigate with a gamepad |
| [3D mouse](spacemouse.md) | Navigate with a 3D mouse |

Turn one on or off in Edit, Preferences, Plugins. Off does not delete anything, and your work comes back when you switch it on. Remove deletes the plugin from your computer.

To install one, press Install under Made by FundaCAD, or use Add a plugin with a web address or a file.
