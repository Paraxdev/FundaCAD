# Plugins

A plugin adds something that not everyone needs. Screws, a game controller, textures on a surface and a link to your printer are all plugins. Keeping them separate means FundaCAD stays small for the person who only wants to sketch and extrude, and the rest is there when you ask for it.

Most of the plugins below are switched on out of the box. You only need this page when you want to turn one off, because it adds a button you never use, or turn one on, because the thing you are looking for is not on the rail.

| Plugin | What it is for |
| --- | --- |
| [Extra Parameters](extra-parameters.md) | Sliders, groups, saved configurations and checks for your parameters |
| [Fasteners](screws.md) | A library of screws, nuts, washers and heat-set inserts |
| [Surface Texture](texture.md) | Knurling, ribs, waves and other textures as real shape |
| [Node Bodies](organic.md) | Smooth, rounded solids built from sized points |
| [3D Printing Toolbox](print-toolbox.md) | Holes and edges that print without supports |
| [Printer connection](printing.md) | Open a part in your slicer and send jobs to your printer |
| [Multi-material](multicolor.md) | Filament slots for multi-colour prints, off by default |
| [Game controller](gamepad.md) | Navigate and run commands from a gamepad or a Steam Deck |
| [3D mouse](spacemouse.md) | Navigate with a 3D mouse |

## Turning a plugin on or off

Open Edit, Preferences (Ctrl+,) and go to Plugins, the last category in the list. Under Installed plugins every plugin has a switch. Flip it and the plugin starts or stops.

Off does not mean gone. The plugin stays on your disk, and anything it wrote into your documents stays there too, so switching it back on later brings your work back. Remove, next to the switch, deletes the plugin from your computer, and you would have to install it again to use it.

Some plugins add a category of their own to Preferences, such as Game Controller. It only shows while the plugin is on.

## Installing a plugin

Plugins made by FundaCAD that are not installed yet appear under Made by FundaCAD on the same page. Press Install on one, read what it asks for, and confirm.

For a plugin from somewhere else, use Add a plugin. Paste a web address and press Read it, or press Choose a file to pick a plugin bundle from your computer. FundaCAD shows what the plugin wants before anything is installed, and it installs only after you agree.

Each row has a What it uses button. It lists what the plugin is allowed to do, such as reading your document, changing it, reading a file you pick, or reaching printers on your local network. A plugin gets what it asked for and nothing more. Have a look before you install something that did not come from FundaCAD, and only install from a source you trust, as you would with any program.
